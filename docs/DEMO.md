# อัดเดโมด้วยบัญชี Google จริง

เว็บเดโมใช้บัญชี Google และปฏิทินจริง แต่ส่ง header `X-Demo-Clock` ให้ API เล่นซ้ำ "วันพายุ" บนวันที่วันนี้ ข้อมูลฝน พยากรณ์รายชั่วโมง ระดับคลอง การจราจร และน้ำท่วมจุดเสี่ยงของ กทม. จึงมาจากฉากที่เขียนไว้ (ป้ายแหล่งข้อมูลจะลงท้ายด้วย `(scenario)`) ส่วนนัดหมายมาจากปฏิทินของบัญชีที่ login

ฉากนี้ผูกกับ "เวลาของวัน" ไม่ผูกกับวันที่ จึงอัดวันไหนก็ได้ บัญชีจริงไม่เห็นนัดของ มิว แม้ปฏิทินจะว่าง

## เวลาในฉาก

| เวลา | สภาพ |
| --- | --- |
| 16:10 | ฟ้ายังโปร่ง ฝนจะมาราว 17:30 |
| 17:45-19:15 | พายุหนัก สูงสุด 52 มม./ชม. ราว 18:15 |
| 18:52 | กลางพายุ น้ำขังตามจุดเสี่ยง |
| 21:00-22:15 | ฝนรอบสอง คลองลาดพร้าวถึงตลิ่ง 21:40 |

เปลี่ยนเวลาระหว่างอัดได้ที่ชิปนาฬิกามุมขวาบนของหน้าสรุป มีให้เลือก 16:10, 18:52, 21:40 และเวลาจริง

## Build และ deploy

ต้อง deploy API ตัวที่มีการแก้นี้ก่อน (ดู [DEPLOY.md](DEPLOY.md) ขั้น 1) แล้ว:

```bash
cd app && flutter build web --release --dart-define=DEMO_CLOCK=16:10 && cd ..
firebase hosting:channel:deploy demo
```

เปิด URL ของ channel `demo` ในหน้าต่าง Incognito แอปจะเริ่มที่หน้าแรกเหมือนผู้ใช้ใหม่ ตั้งบ้าน แล้วเชื่อม Google ตามปกติ Login จาก URL นี้จะกลับมาที่ URL เดิม (API อนุญาต `ai-cup-511208--*.web.app` อยู่แล้ว)

`app/build/web` ถูกเขียนทับ ก่อน deploy เว็บหลักรอบถัดไปต้อง build ใหม่โดยไม่ใส่ `DEMO_CLOCK`

## เตรียมปฏิทิน

นัดจากปฏิทินออกเดินทางจาก "บ้าน" ที่ตั้งไว้ในแอป ผลด้านล่างได้จากการยิง API จริงโดยตั้งบ้านที่ลาดพร้าว (13.8160, 100.5900) ด้วยกฎตัดสินใจล้วน บน Cloud Run Gemini จะเขียนข้อความเอง แต่คำตัดสินถูกล็อกให้ตรงกับกฎ

สร้างนัดในวันที่อัด เวลาและสถานที่ตามนี้ (ใส่ช่อง Location ให้ค้นเจอ):

| นัด | เวลา | วิธีเดินทาง | 16:10 | 17:40 | 18:52 |
| --- | --- | --- | --- | --- | --- |
| ประชุมที่อโศก (Location: Terminal 21) | 19:30 | รถยนต์ | ออกก่อน 16:50 | รอถึง 19:45 | รอถึง 19:45 + จุดน้ำท่วมสุขุมวิท |
| กินข้าวที่สีลม (Location: Silom Complex) | 19:00 | รถยนต์ | ออกก่อน 16:40 | รอถึง 19:15 | รอถึง 19:15 |
| ดูหนังที่สยามพารากอน | 19:00 | มอเตอร์ไซค์ | ออกก่อน 16:50 | เปลี่ยนไปนั่งรถไฟฟ้า | เปลี่ยนไปนั่งรถไฟฟ้า |
| ดูหนังที่สยามพารากอน | 19:00 | รถไฟฟ้า | ออกก่อน 16:55 | ออกได้เลย | ออกได้แต่เลยนัด |

วิธีเดินทางเปลี่ยนได้ในหน้าตั้งค่า หรือในหน้ารายละเอียดของนัด

## โหมดน้ำท่วมที่บ้าน (21:40)

หน้าสรุปจะเข้าโหมดน้ำท่วมเฉพาะเมื่อบ้านอยู่ใกล้คลองลาดพร้าว ตั้งบ้านแถว (13.8160, 100.5900) แล้วได้ "อันตราย: น้ำจะถึงหน้าบ้านใน 40 นาที" ถ้าบ้านอยู่ที่อื่นจะได้แค่ "เฝ้าระวังน้ำขังแถวบ้าน"

## ข้อควรรู้

- ฝนในฉากตกเหมือนกันทั้งเมือง ทุกเส้นทางเจอพายุ แต่จุดน้ำท่วมขึ้นเฉพาะเส้นทางที่ผ่าน 8 จุดเสี่ยงใน `data/bkk_flood_risk_points.json` (เช่น รัชดาฯ หน้าศาลอาญา, สุขุมวิท อโศก-พร้อมพงษ์, พระราม 4)
- เส้นทางในฉากเป็นเส้นตรงจากบ้านถึงปลายทาง ยกเว้นเส้นสีลม-ลาดพร้าวของ มิว ที่วาดไว้ตามถนนจริง
- รายงานน้ำท่วมจากชุมชนในฉากผูกกับวันที่ 29 ก.ย. 2026 จึงไม่ขึ้นในวันอื่น
